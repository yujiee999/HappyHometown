# ER阳性转移乳腺癌GSE124647-2026-06-29

## 数据集概况

- 数据集名称：SET ER/PR metastatic HR+/HER2− breast cancer cohort
- 疾病/转移部位：HR+/HER2− 转移性乳腺癌；GEO 样本级元数据覆盖淋巴结、软组织、乳腺局部/胸壁、肝、皮肤、骨、肺、卵巢、胸膜和其他内脏部位
- 样本类型和样本量：140 份患者转移灶活检；部位构成为淋巴结 44、软组织 32、乳腺 19、肝 16、皮肤 12、骨 11、肺 3、卵巢 1、胸膜 1、其他内脏 1
- 平台：Affymetrix Human Genome U133A Array（GPL96）；论文另在 53 份剩余 RNA 中验证了定制靶向 RNA-seq/ESR1 配体结合域测序，但 GEO 主体可下载数据是 140 例表达芯片
- 数据模态：bulk 表达芯片 + 临床结局/治疗敏感性 + ER/PR 状态 + 活检部位；部分样本元数据含 SET ER/PR 指数、ESR1 突变及突变等位基因频率
- 物种与来源：Homo sapiens，患者转移灶活检

- GEO：[GSE124647](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE124647)

## 关联论文

- Sinn BV et al. SET ER/PR: a robust 18-gene predictor for sensitivity to endocrine therapy for metastatic breast cancer. npj Breast Cancer. 2019.
- 与本轮新文献 [[ACSS2代谢表观遗传氟维司群耐药-2026]] 不是同一研究，但可作为独立、患者来源的 ER+ 转移灶临床验证层。

## 可用于验证的具体假设

1. `ACSS2 + 脂肪酸合成 + 乙酸利用/乙酰辅酶A` 程序是否在肝转移中高于骨、肺或卵巢转移。
2. ACSS2 复合程序是否与较低 SET ER/PR、ESR1 突变或更短内分泌治疗 PFS 相关。
3. 脑转移笔记中的 `ACSS2–SLC7A11/铁死亡保护` 与本轮 `ACSS2–脂质合成/表观遗传` 程序在不同转移器官中是否出现分流。
4. 在控制活检部位、既往内分泌敏感性和 ER/PR 状态后，ACSS2 相关程序是否仍保留独立结局关联。

## 建议分析路径

1. 下载 CEL 文件，用 RMA 统一标准化并完成探针到基因映射。
2. 先按 `site biopsied` 做样本量检查；器官比较优先肝（n=16）与骨（n=11），肺（n=3）、卵巢（n=1）仅作个案/方向性展示。
3. 构建至少三个模块：ACSS2/乙酸利用、脂肪酸合成、铁死亡防御；不要以 ACSS2 单基因替代通路结论。
4. 将 SET ER/PR、ESR1 mutation/MAF、PFS、OS 和既往内分泌敏感性作为协变量或分层变量。
5. 用留一法或 bootstrap 检查结果是否由单个器官小样本驱动；不适合直接训练复杂机器学习模型。

## 下载难度和注意事项

- 下载难度：低。CEL、Series Matrix 和样本元数据均由 GEO 公开提供。
- 这是 bulk 表达芯片，无法区分肿瘤细胞和免疫/基质细胞来源；器官差异可能反映组织成分。
- 样本部位严重不均衡：肺仅 3 例、卵巢仅 1 例，不能据此给出稳健的肺/卵巢器官嗜性结论。
- “Breast”样本属于转移性队列中的乳腺/局部活检标签，不应自动等同于未经治疗的原发乳腺癌。
- GEO 主体是 GPL96 芯片。论文中 53 例定制靶向 RNA-seq 的结果可用于交叉参考，但不能把 GSE124647 整体标注为 RNA-seq。
- ESR1 突变和治疗结局受既往治疗线次影响；做器官比较时必须控制临床混杂。

## 核验记录

- 2026-06-29 通过 NCBI GEO ESummary 与 GSE124647 family SOFT 核验 accession、平台、140 例样本和逐样本 `site biopsied` 字段。

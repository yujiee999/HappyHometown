# Path2Space代码与处理数据

## 数据集名称

Path2Space software, example data and processed breast-cancer spatial/pathology outputs

## 疾病/转移部位

- 疾病：人乳腺癌。
- 训练、外部验证与 TCGA 扩展以原发乳腺癌为主，不是脑、肺、骨或卵巢转移灶专属队列。
- 对用户课题的主要价值是把转移灶 H&E 转成可验证的“预测空间表达”，属于方法迁移资源，不是器官转移生物学的直接证据。

## 样本类型和样本量

- 实测空间转录组 QC 总表：101 张切片，Bassiouni 43、HTAN 48、Martinez 5、HEST 5。
- 论文最终保留的实测 ST 切片：40 张，Bassiouni 22、HTAN 9、Martinez 4、HEST 5。
- TCGA 推断队列：976 例乳腺癌肿瘤，用于大规模空间推断和 SpatioTypes。
- 扩展仓库反应标签：343 条，TransNEO 154、IMPRESS 126、PBCP 37、Cedars-Sinai 26。
- HER2-SPAND 处理表：186 例，TransNEO 61、IMPRESS 62、PBCP 37、Cedars-Sinai 26。
- 上述数字来自论文摘要、ScienceDirect 页面以及作者 2026 年公开的 QC/反应表；同一患者可能有多张切片，不能把所有“切片数”直接视为独立患者数。

## 平台

- 实测空间层：10x Genomics Visium 为主，spot 直径约 55 μm。
- 图像层：H&E whole-slide image / 与 spot 对齐的 224×224 图块。
- 特征与建模：CTransPath 类病理特征、PyTorch 多层感知机、多基因逐 spot 回归。
- 下游：SpaGCN、Seurat、SpaCET/监督去卷积、SpatioTypes、SPAND、治疗反应分类。
- 推荐环境：Python 3.10；训练和大规模推断建议 NVIDIA GPU、CUDA 12、显存至少 16 GB。作者主要在 Linux/HPC 验证。

## 可获得的数据层级

- Zenodo v1.0.1：脚本、教程、依赖环境、3.8 GB 示例输入和 232.8 MB 示例输出，总体约 4.1 GB。
- GitHub 扩展仓库：40 张保留 ST 切片的 QC 表、逐队列空间聚类比例、TCGA/METABRIC SpatioTypes、343 条反应标签、186 例 HER2-SPAND、去卷积与基准比较结果。
- 原始数据：论文使用公开来源，但原始 ST、WSI、TCGA/METABRIC 与临床治疗队列并未全部打包在一个 accession 下；必须按来源队列分别下载并遵守访问许可。
- 该资源应标记为“软件 + 示例 + 处理数据”，不是一个新的原始测序 accession。

## 可用于验证的具体假设

- 同一 CellChat 通讯轴若在 MT 中增强，其配体高区、受体高区和相应细胞类型是否在 H&E 推断空间图中相邻，而不是仅在全样本平均表达上相关。
- 脑转移 CD163+ 巨噬细胞抑制生态位是否与肿瘤细胞 IFN/STAT、PD-L1、GAS6-TAM 或 PGE2-EP4 程序形成稳定邻域。
- 肺转移中性粒细胞/血管通透性程序、骨转移巨噬细胞-骨细胞程序是否表现出比 PT 更高的空间聚集或邻域异质性。
- 同一器官内，预测的免疫排斥型与免疫浸润型切片能否被多重 IHC、RNAscope 或小规模实测 ST 重现。
- MT 特异细胞群的 signature 是否定位于可解释的组织学区域，并在不同患者中重复出现。

## 下载难度和注意事项

- 下载难度：中等。Zenodo 示例包约 4.1 GB，可直接下载；完整复现需分别获取多队列 WSI、ST 和临床数据，难度较高。
- 优先使用 2026-05-13 发布的 Zenodo v1.0.1；初版依赖文件存在重复包、无效 `skimage==0.0` 和非正式 `torchvision` 构建等问题。
- 核心模型/Zenodo 条款限非商业学术研究；扩展 GitHub 为 Apache-2.0，但不能覆盖模型专利条款及原始临床队列许可。
- 40 张最终 ST 切片只是训练/验证锚点；对远处转移灶应用前必须进行器官和制片条件分层的外部校准。
- 预测表达不是测量值。正式结论至少需要一种正交验证：实测 ST、RNAscope、IHC/IF 或独立转录组证据。
- 对 PT/MT 比较应锁定相同扫描、染色和组织处理流程，并把患者、器官、切片批次作为分层因素，避免模型把技术域差异当作转移特异信号。

## 推荐复用顺序

1. 先运行 Zenodo 小示例，验证环境与图像/表达坐标格式。
2. 用已有实测 ST 或多重染色样本做本地校准，评估目标 signature 的逐 spot 相关与空间定位。
3. 只把通过校准的 gene set 扩展到大 H&E 队列；不要先做全基因无约束解释。
4. 将预测地图用于样本分层和实验优先级排序，再以正交实验确认关键生态位。

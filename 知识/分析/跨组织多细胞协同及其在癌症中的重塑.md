# 核心问题

这篇文章试图回答一个比“有哪些细胞类型”更高一层的问题：不同组织中的多种细胞类型是否会以稳定、可复现的组合方式共同出现，并构成组织稳态中的功能性多细胞生态单元；在癌症发生发展过程中，这些健康组织生态单元又如何被破坏和重塑。

作者的核心概念是 **cellular module, CM**，即由多个细胞亚群组成的协同模块。CM 不是简单的细胞类型列表，而是基于样本间细胞亚群丰度协方差推断出来的多细胞组织结构。文章进一步提出 **CoVarNet** 框架，用细胞亚群频率的共变关系来识别跨组织的多细胞协调网络。

# 一句话总结

作者整合 35 种健康人体组织和 29 种癌症类型的单细胞转录组数据，提出 CoVarNet 识别跨组织 cellular modules，并用 GTEx、空间转录组、细胞通讯、细胞因子响应、衰老和绝经相关表型进行验证；最后证明癌症进展伴随两类多细胞生态重塑：一方面丢失组织特异性健康 multicellular organization，另一方面形成跨癌种收敛的 cancer-associated cellular module。

# 文章叙事逻辑

## 1. 从细胞图谱进入组织生态问题

文章开头指出，Human Cell Atlas 等工作已经系统刻画了细胞类型多样性，但仍然缺少一个机制框架解释：

- 多种细胞类型如何在组织生态位中协同出现；
- 这些细胞组合是否跨组织复现；
- 这些组合是否具有空间组织、细胞通讯和表型关联；
- 癌症是否会重塑这些健康组织多细胞结构。

因此，文章不是单纯构建 cell atlas，而是试图从 cell diversity 转向 **multicellular coordination**。

## 2. 构建健康 pan-tissue 单细胞参考

作者首先整合健康成人组织单细胞数据，建立跨组织参考图谱。主要数据规模如下：

- 健康单细胞图谱：2,293,951 个高质量细胞；
- 样本数：706 个健康样本；
- 供体数：317 个；
- 组织数：35 种人体组织；
- 数据集：33 个 scRNA-seq 数据集，来自 26 个 cohort；
- 技术标准：新鲜样本、10x Genomics 单细胞数据，尽量避免 frozen sample 和 single-nucleus 数据带来的系统偏差；
- 注释结果：76 个非上皮细胞亚群和 26 个 epithelial cell types。

这一部分的功能是提供一个足够大、足够广的 reference space，使作者可以比较不同组织中非上皮免疫、基质、内皮和髓系细胞的组织偏好与共变关系。

## 3. 提出 CoVarNet，定义 cellular modules

作者随后提出 CoVarNet。其基本思想是：如果一组细胞亚群在多个样本中反复共同升高或共同出现，那么它们可能构成一个多细胞协调模块。

CoVarNet 的输入是样本层面的细胞亚群频率矩阵。作者为了让不同 cell type 内的亚群可比，使用的是 **within-cell-type subset frequency**，并进行 min-max normalization，以减少某些 cell type 亚群数量更多造成的偏差。

CoVarNet 有两个并行模块：

1. **NMF 模块**  
   对 cell subset frequency matrix 做 non-negative matrix factorization，识别共同出现的细胞亚群集合。NMF factor 中权重最高的细胞亚群作为候选 CM nodes。健康 pan-tissue 分析中，作者用 nsNMF，rank 从 2 到 20 评估，最终根据 cophenetic correlation coefficient 选择 rank = 12。

2. **Correlation-specificity 模块**  
   对细胞亚群两两计算 Pearson correlation，并结合 FDR 和 specificity index 筛选 specifically correlated subset pairs。这些 pair 构成潜在 edges。

之后，作者把 NMF 定义的 node 与 correlation-specificity 定义的 edge 结合，构建 CM networks，并用 connectivity score 和 permutation test 评估网络是否显著。

最终作者在健康 pan-tissue atlas 中识别到 **12 个 cellular modules**。

## 4. 证明 CMs 具有跨组织性和组织偏好

12 个 CMs 不是单一组织内的局部结构，而是具有跨组织分布。作者发现：

- 多数非上皮细胞亚群参与至少一个 CM；
- 一部分细胞亚群参与多个 CM，说明同一细胞亚群可在不同组织生态中承担不同协同角色；
- 每个样本可按最高 CM activity 分成 CMT，即 CM type；
- 每个 CMT 都包含多个组织，支持 CMs 的 cross-tissue nature。

CM 的组织偏好也很清楚：

- CM04、CM05、CM06、CM09 富集于免疫器官或血液相关组织；
- CM07、CM12 偏向生殖系统，与特化 fibroblasts 相关；
- CM02、CM03 偏向泌尿或胃肠系统；
- CM08 富集于屏障组织，可能对应 mucosa-associated immune organization；
- CM10 像 vascular unit，包含 pericyte、smooth muscle、vascular endothelial cells；
- CM11 偏向肺、肾、肝、脂肪，可能与代谢过程相关；
- CM01 分布最广，包含 tissue-resident macrophage、universal fibroblast 和 lymphatic endothelial cells，像一种 universal multicellular organization。

## 5. 用 GTEx bulk RNA-seq 验证 CMs

作者用 GTEx bulk RNA-seq 做外部验证：

- 原始 GTEx 数据：17,382 个 bulk RNA-seq samples；
- 筛选后用于分析：12,240 个样本，覆盖 23 个与单细胞图谱重叠的组织；
- 用单细胞 pseudo-bulk CMT 的 top DEGs 作为 CMT signatures；
- 使用 Seurat AddModuleScore 给 GTEx bulk 样本打分；
- 排除低置信度样本后，11,962 个 GTEx 样本被分入 12 个 CMT。

GTEx 中 CMT 可以被良好恢复，且 signature 表达与单细胞结果一致。这一步的作用是证明 CoVarNet 识别的 CMs 不是单细胞数据特有的噪音，而是可在 independent bulk transcriptomic datasets 中被捕捉的组织结构。

## 6. 用空间组学证明 CMs 有空间结构

作者使用 Visium 和 Xenium 数据验证 CMs 的 spatial organization。

主要空间方法：

- 用 cell2location 将 scRNA-seq 细胞亚群映射到空间转录组 spot；
- 用 NMF-derived weights 计算空间位置上的 CM activity；
- 用 colocalization score 衡量 CM 内部细胞亚群在空间中的共定位；
- 用 global bivariate Moran's I 计算 aggregation score；
- 用 CellCharter 作为空间 niche 的正交验证；
- 用 Xenium 在肠道组织中做更高分辨率验证。

代表性发现：

- 皮肤中 CM08 和 CM10 分别对应免疫防御相关结构和血管结构；
- 小肠中 CM05 富集在 Peyer's patch，包含 naive B、naive T、Tfh 等，类似 mucosal immunity 的 inductive module；
- CM02/CM03 主要位于 intestinal mucosa，包含 IgA plasma cells、memory/resident memory T cells、innate immune cells，类似 effector module。

这一部分是文章逻辑中的关键桥梁：CoVarNet 是基于样本间丰度共变推断的，但作者用空间组学证明这些模块确实能映射到组织中的局部生态结构。

## 7. 证明 CM 内存在细胞通讯与局部调控

作者进一步分析 CM 内部的 cell-cell communication：

- 使用 CellPhoneDB 进行 ligand-receptor mediated communication；
- 每个细胞亚群最多 subsample 1,000 个细胞，避免大亚群支配 null distribution；
- 使用 CellChat 作为替代工具验证；
- 比较 high CM activity samples 与 low CM activity samples 中 CM component cell subsets 的通讯差异。

作者发现，高 CM activity 样本中，CM 内部细胞通讯通常更强，说明 CM activity 不只是细胞比例变化，也反映局部细胞互作增强。

此外，作者使用 Immune Dictionary 进行 cytokine response inference：

- Immune Dictionary 包含 86 种 cytokine 的 cell-type-specific response；
- 对 CM 中免疫细胞亚群在 CMT-specific context 下的 DEGs 做 enrichment；
- 推断不同 CM 中哪些 cytokines 可能驱动细胞亚群的表型变化；
- 在小肠空间数据中验证 IL7、IL18、LTA、LTB 等 cytokines 的 niche-specific spatial enrichment。

这里的关键结论是：CM 不只是“细胞共现”，而是包含 ligand-receptor communication、cytokine response 和空间组织的多层次组织生态单元。

# 两个健康生理表型示例

## 1. 脾脏衰老：CM05 上升，CM06 下降

作者在脾脏中发现 CM05 随年龄升高，而 CM06 随年龄降低。进一步分析发现，多个随年龄变化的 immune subsets 属于 CM05 或 CM06，说明 cross-tissue CM 能捕捉 tissue-specialized ageing dynamics。

CM05 中随衰老扩张的细胞包括 B cell、CD4 T cell 和 innate lymphoid cell 相关亚群。作者用 SCENIC 推断这些亚群的 regulons，发现它们共享一组随年龄升高的 regulon activity，包括 AP-1 相关转录因子，如 ATF3、FOS、FOSB、JUN、JUNB、JUND、KLF6、NFKB1。NR4A1 也被强调为与 T cell dysfunction 和 immune ageing 相关的节点。

这一部分的意义是：CM 可连接 molecular regulation、cellular abundance 和 tissue-level multicellular coordination。

## 2. 乳腺绝经轨迹：CM12 捕捉 fibroblast dynamics

作者重点分析 breast-enriched CM12。CM12 包含三个 specialized fibroblast subsets 及其他细胞。用 DIALOGUE 识别 CM12-related multicellular programmes 后，作者发现一个 programme 在绝经前样本中更高，而绝经后样本炎症分数下降。

细胞层面上，S10 和 S06 fibroblast subsets 在绝经后下降最明显：

- S10 高表达 collagen genes，如 COL1A1、COL1A2、COL3A1；
- S10 主要分布在 connective tissue；
- S06 更集中于 lobules；
- S09 和部分免疫细胞更多位于 ductal regions，绝经后变化较小。

作者基于 CM12 cell subset frequencies 构建 menopausal trajectory，发现 S10 沿轨迹持续下降，S06 后期下降，并在外部乳腺数据集中验证。

这一部分的功能是说明 CM 可以作为 tissue physiological transition 的 readout，捕捉年龄、激素状态和基质细胞动态。

# 癌症部分：multicellular rewiring

## 数据构建

作者将框架扩展到肿瘤微环境，建立 pan-cancer single-cell atlas：

- 癌症类型：29 种；
- 临床样本：1,062 个；
- 供体：717 个；
- 高质量细胞：3,038,535 个；
- 注释结果：91 个非上皮细胞亚群，其中包括 76 个健康参考亚群和 15 个 cancer-associated subsets。

癌症样本注释使用 TOSICA，这是一个 transformer-based transfer learning annotation framework。作者用健康 76 个非上皮亚群和 15 个文献报道的 cancer-associated subsets 构建 reference model，再预测 pan-cancer atlas 中非上皮细胞身份，并去除预测概率小于 0.5 的细胞。

## 癌症进展的两类生态重塑

作者分析了 8 个有 matched healthy、adjacent non-tumour 和 tumour samples 的癌种：

- CRC
- KIRC
- HCC
- LUAD
- HNSC
- OV
- cSCC
- CESC

他们首先把健康 CMs 映射到这些条件中，发现多数癌种的 tumour samples 中组织特异性 healthy CM activity 明显下降。这说明癌症会破坏原本的 tissue-specific multicellular ecosystem。

随后作者在 pan-cancer atlas 中重新运行 CoVarNet，识别 cancer-associated CMs，即 cCMs。最重要的是 **cCM02**：

- cCM02 主要由 cancer-associated cell subsets 组成；
- 在多个癌种的 tumour samples 中富集；
- 从 healthy 到 adjacent non-tumour 再到 tumour，cCM02 activity 逐渐升高；
- cCM02 内部 co-occurring cell subset pairs 在肿瘤中增强；
- 因此 cCM02 被解释为收敛性的 cancer-associated TME ecosystem。

文章最重要的癌症结论是：

> 肿瘤进展伴随两种并行的 multicellular ecosystem rewiring：一方面组织特异性健康 CM 被削弱；另一方面跨癌种共享的 cancer-associated CM 逐渐形成。

## cCM02 programme 与临床相关性

作者进一步分析 cCM02：

- cytokine analysis 提示 interferon、IL-18、IL-15 是重要调控介质；
- DIALOGUE 识别出 cCM02 activity 相关 MCP，该 programme 在多数细胞亚群中上调 S100 family genes，如 S100A2、S100A8、S100A9；
- 用 TCGA bulk RNA-seq 验证该 programme 在多癌种 tumour vs adjacent 中上调；
- 在 51 个 pre-invasive lung lesions 中，该 programme 在最终进展为 invasive lung cancer 的病灶中更高，而自发 regression 的病灶中较低。

这一步把 multicellular ecosystem 从描述性 atlas 推到潜在临床应用：cCM02 programme 可能用于早期癌症进展风险评估。

# 方法细节整理

## 健康单细胞数据 QC

纳入标准：

- 成人样本；
- fresh sample；
- 10x Genomics scRNA-seq；
- 单细胞而非单核；
- 无细胞富集或包含免疫、上皮、内皮、基质混合 compartment 的样本。

QC 标准：

- 500-8,000 genes per cell；
- 1,000-100,000 gene counts；
- mitochondrial gene counts < 20%；
- 使用 Scrublet 去除 doublet score 超过 cohort 内 90th percentile 的细胞；
- 删除高质量细胞少于 50 的样本。

预处理：

- 统一到 21,812 个常见基因；
- library size normalization 到 10,000；
- log transformation；
- 选择 2,000 HVGs；
- HVG 选择前排除 immunoglobulin、TCR、ribosomal protein-coding、heat shock 和 mitochondrial genes；
- 回归总 counts、mitochondrial percentage、cell cycle effects；
- center 和 scale HVGs。

## 数据整合与细胞注释

- 用 scIB 比较 BBKNN、Harmony、Scanorama、scVI、scANVI、SCALEX；
- 综合 batch correction 与 biological conservation 后，BBKNN 表现最好；
- PCA 取 50 PCs；
- 用 BBKNN 构建 batch-corrected graph；
- 用 UMAP 可视化；
- 一级 Leiden clustering resolution = 0.1，注释 8 个 broad cell types；
- 后续按 cell type/context 继续细分；
- CellTypist 辅助免疫细胞注释；
- epithelial cells 因高度组织特异性，不纳入 CoVarNet 的 CM 推断。

## CoVarNet 关键步骤

1. 构造 corrected cell subset frequency matrix；
2. 对频率矩阵做 nsNMF；
3. 用 CCC 选择 NMF rank；
4. 取每个 factor 中 top weighted subsets 作为候选 nodes；
5. 用 Pearson correlation + FDR + specificity index 筛选 specifically correlated subset pairs；
6. 将 nodes 与 edges 合并为 CM networks；
7. 用 connectivity score 和 10,000 次 permutation 评估显著性；
8. 用 NMF coefficient matrix 定义样本层面 CM activity；
9. 每个样本按最高 CM activity 分配 CMT label。

## 空间分析

- Visium：用 cell2location 将细胞亚群映射到 spot；
- cell2location 参数包括 expected cell abundance per spot N = 5，alpha = 20；
- CM activity = CM component cell abundance 的 weighted aggregation；
- colocalization score = CM 内 subset-pair spatial correlation 相对于全局 correlation background 的 ranking；
- aggregation score = global bivariate Moran's I；
- CellCharter 用作空间 niche 验证；
- Xenium 用于肠道 CM02/CM03 高分辨率验证。

## 细胞通讯

- CellPhoneDB 用于 ligand-receptor interaction；
- 每个细胞亚群 subsample 至最多 1,000 个细胞；
- 全局分析不依赖 CM；
- comparative analysis 按 High CM activity vs Low CM activity 分组；
- CellChat 作为替代工具验证；
- Immune Dictionary 用于 cytokine response inference；
- clusterProfiler hypergeometric test 做 cytokine response enrichment。

## 多细胞程序与调控

- SCENIC 用于脾脏 CM05 中 regulon inference；
- DIALOGUE 用于识别 CM-related multicellular programmes；
- AUCell 用于计算 inflammatory scores；
- PHATE + Palantir 用于乳腺绝经轨迹；
- TCGA bulk RNA-seq 和 pre-invasive lung lesion data 用于 cCM02 programme 外部验证。

# 文章的技术贡献

## 1. 从“细胞类型图谱”推进到“多细胞生态模块”

传统单细胞图谱主要关注细胞类型发现、marker gene 和组织分布。本文强调细胞亚群的共变、共定位和互作，把组织看作由多个可重复的 multicellular modules 组成。

## 2. 用 abundance covariance 捕捉组织层级协调

CoVarNet 的核心假设是细胞亚群丰度在样本间的协方差反映组织生态中的协同关系。这一点不同于只基于空间邻近或 ligand-receptor 表达的传统 niche 推断方法。

## 3. 将单细胞、bulk、空间、细胞通讯和表型数据串联

文章的说服力来自多层验证：

- 单细胞 atlas 发现 CM；
- GTEx bulk RNA-seq 验证 CMT；
- Visium/Xenium 验证空间组织；
- CellPhoneDB/CellChat 验证互作；
- Immune Dictionary 推断 cytokine landscape；
- SCENIC 和 DIALOGUE 连接分子程序；
- 衰老、绝经、癌症进展和 pre-invasive lesion outcome 连接生物学表型。

## 4. 提出癌症重塑的双重模型

癌症不是简单增加或减少某一类免疫细胞，而是同时发生：

- healthy tissue-specific CM 的瓦解；
- convergent cancer-associated CM 的形成。

这个观点非常适合解释为什么同一个肿瘤类型在不同组织背景中会呈现不同免疫生态，也适合解释不同癌种在进展后又会收敛出类似的 TME programmes。

# 局限性

作者明确提到的局限包括：

- CoVarNet 当前没有显式纳入 epithelial cells；
- 没有显式纳入 extracellular matrix 和 microbiome；
- 细胞共变不等同于因果关系；
- 空间验证受限于 Visium 的分辨率和基因覆盖；
- 当前表型关联仍依赖已有公开数据，更多临床 phenotype 和更大 cohort 可以增强转化意义。

从使用角度看，还需要注意：

- cell subset frequency covariance 容易受到组织采样、消化偏好和数据整合影响；
- CM activity 既反映细胞比例，也可能反映 cohort composition；
- ligand-receptor analysis 是推断性结果，需要空间邻近、蛋白水平或功能扰动验证。

# 对乳腺癌转移研究的启发

这篇文章为“同样是乳腺癌转移，不同器官为什么呈现不同免疫生态结构”提供了一个非常有用的理论框架。

其核心启发是：转移灶免疫结构不是由肿瘤细胞谱系单独决定，而是由转移器官的 resident stromal、endothelial、epithelial 和 immune compartments 提供不同的 ligand milieu 和 tissue-specific constraints。不同器官的健康 multicellular organization 会被肿瘤重新利用、破坏或重塑，因此同一乳腺癌在肺、脑、卵巢、胸壁等部位可以形成不同的 sender-receiver 网络。

可以将我们的转移灶分析放在这个框架下理解：

- 肺转移呈现 lung epithelium/stroma/endothelium 与 Mph-MARCO、cDC2、CD8_Temra/Tex 的 ICAM1/SELPLG/CXCL12 轴，像一个肺部黏附-髓系抗原呈递生态；
- 脑转移呈现 BBB-like/IFN endothelium 与 iCAF chemokine 对 CD4、plasma cell 和 stress/IFN-like macrophage 的组织作用，强调血管屏障和趋化生态；
- 卵巢转移呈现 Mph-SPP1/FOLR2 与 Bm 的 APP-CD74、BAFF-BAFFR、SELPLG-SELL 轴，像 macrophage-B cell/APC-like niche；
- 胸壁复发/转移呈现 ECM-rich、CAF/mast/endothelial 与 Treg/Mph-MKI67 的 collagen、CXCL12、LTA/CCL22 等轴，更接近 wound-healing-like stromal immunoregulatory niche。

因此，我们的器官转移结果可以被概括为：乳腺癌转移过程中，肿瘤细胞进入不同器官后，不是在一个空白环境中生长，而是在不同组织既有 multicellular ecosystem 的约束下重新布线。每个器官的局部细胞组成和 ligand-receptor landscape 决定了免疫细胞的募集、滞留、空间接触和功能状态，最终形成器官特异性的转移免疫生态。

# 可用于论文写作的表述

英文表述：

Breast cancer metastases exhibited organ-specific immune ecosystem rewiring, consistent with the concept that multicellular coordination is shaped by tissue-resident stromal, endothelial, epithelial and immune compartments. Rather than reflecting tumour-intrinsic programmes alone, metastatic immune niches appeared to arise from organ-specific ligand milieus that differentially organized immune recruitment, retention, antigen presentation, extracellular-matrix remodelling and checkpoint-mediated restraint.

中文表述：

这些结果提示，乳腺癌转移灶的免疫生态并非由肿瘤细胞谱系单独决定，而是由不同转移器官中预先存在的组织特异性多细胞结构所塑形。器官驻留的内皮、基质、上皮和免疫细胞通过差异化的 ligand milieu 和细胞通讯网络，调控免疫细胞募集、空间滞留、抗原呈递、基质重塑及免疫检查点约束，从而使同一乳腺癌来源的转移灶在肺、脑、卵巢和胸壁中呈现截然不同的免疫生态位。
